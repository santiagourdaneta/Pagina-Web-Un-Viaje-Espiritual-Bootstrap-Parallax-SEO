 # 🌍 Página Web "Un Viaje Espiritual" | Bootstrap, Parallax y SEO

Este proyecto es una página web moderna y atractiva desarrollada como ejercicio de maquetación y diseño, enfocándose en tres pilares principales del desarrollo frontend: **Bootstrap para la estructura responsiva**, **efecto Parallax para una experiencia visual inmersiva**, y la implementación de **principios básicos de SEO** para la optimización de motores de búsqueda.

El tema central de la página es "Un Viaje Espiritual", utilizando imágenes y contenido que evocan tranquilidad y exploración.

## ✨ Características Destacadas

* **Diseño Responsivo:** Implementación completa del framework **Bootstrap** (Grid System) para asegurar que la página se vea excelente en cualquier dispositivo (móvil, tablet, escritorio).
* **Efecto Parallax:** Uso de CSS y JavaScript para crear un desplazamiento visual dinámico y profundo, donde las imágenes de fondo se mueven más lento que el contenido del primer plano.
* **Optimización SEO:** Estructura HTML semántica, uso de etiquetas meta relevantes (`title`, `description`, `keywords`), encabezados jerárquicos (`H1`, `H2`), y texto alternativo en imágenes para mejorar la visibilidad en buscadores.
* **Código Limpio:** Separación clara de la estructura (HTML), estilos (CSS) y lógica de interacción (JavaScript).

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del contenido.
* **CSS3:** Estilos personalizados y la implementación del efecto Parallax.
* **JavaScript:** Lógica para gestionar el efecto Parallax.
* **Bootstrap:** Framework CSS para el layout responsivo, componentes (ej. navbar) y estilos rápidos.
